# 운동 기록용

아이폰 홈 화면에 추가해서 쓰는 개인 운동 기록 웹앱입니다. 서버가 없고, 모든 기록은 **내 폰 안**에만 저장됩니다. (TypeScript + Preact + Vite## 1. 내 폰에서 쓰기 (한 번만)

1. GitHub 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다.
2. `main` 브랜치에 올리면 Actions가 자동으로 검사·빌드·배포합니다. 몇 분 뒤 `https://내아이디.github.io/저장소이름/` 주소에서 열려요.
3. 아이폰 **사파리**로 그 주소를 엽니다.
4. 공유 버튼 → **홈 화면에 추가** → 추가.
5. **이후에는 홈 화면 아이콘으로만** 사용하세요. (사파리 탭과 홈 화면 앱은 저장 공간이 따로라서, 사파리에서 입력한 기록은 홈 화면 앱에 보이지 않아요.)

> 앱에는 개인 데이터가 들어 있지 않아요(기록은 폰에만 저장). 그래서 저장소가 공개여도 기록이 노출되지는 않습니다.

.

## 2. 기록 지키기

- **설정 → 백업 파일 만들기**로 가끔 JSON 파일을 저장해 두세요 (iCloud Drive "파일에 저장" 등).
- 폰을 바꾸면: 새 폰에서 같은 주소를 홈 화면에 추가 → **설정 → 백업 파일 불러오기**.
- 홈 화면에서 앱 아이콘을 삭제하면 기록도 같이 지워집니다. 삭제 전에 꼭 백업하세요.

## 3. 앱을 고쳐서 다시 올릴 때

```bash
npm ci
npm run dev        # 컴퓨터에서 미리 보기
npm run check      # 타입 검사 + 테스트 + 빌드
npm run e2e        # 화면 테스트
```

- `main`에 올리면 자동 배포됩니다. 버전 표시를 바꾸려면 `package.json`의 `version`을 올리세요(캐시 버전은 자동).
- 앱을 열면 "새 버전이 준비됐어요 → 새로고침"이 떠요. 기록 데이터는 그대로 유지돼요.
- 코드 구조와 작업 규칙은 `CLAUDE.md`, 지금까지의 경과는 `HANDOFF.md`를 보세요.

## 4. 알아 둘 점

- **휴식 종료 알림**: 앱이 켜져 있을 때 소리·화면으로 알려요. 화면을 잠그거나 다른 앱으로 가면 아이폰이 웹앱을 멈춰서 알림이 안 올 수 있어요. 그래서 운동 중에는 화면이 꺼지지 않게 유지하는 옵션(기본 켜짐)을 넣었어요. 잠금 상태에서도 확실히 알리려면 서버가 필요한 푸시 알림을 따로 붙여야 합니다.
- 소리는 무음 스위치 상태에 따라 안 들릴 수 있어요.
- 사진은 640px로 줄여서, 움짤(GIF)은 5MB 이하면 원본으로 저장해요.
