# 운동 기록용

아이폰 홈 화면에 추가해서 쓰는 개인 운동 기록 웹앱입니다. 서버가 없고, 모든 기록은 **내 폰 안**에만 저장됩니다. (빌드 과정 없는 순수 HTML/CSS/JS)

## 1. 내 폰에서 쓰기 (한 번만)

1. 이 폴더 전체를 무료 호스팅에 올립니다. (HTTPS 주소가 필요해요)
   - **GitHub Pages (추천)**: 새 저장소 만들기 → `Add file → Upload files`로 이 폴더 안의 파일을 전부 끌어다 놓기(폴더 구조 그대로) → `Settings → Pages → Branch: main / (root)` 저장 → 몇 분 뒤 `https://내아이디.github.io/저장소이름/` 주소 생성
   - 그 밖에 Cloudflare Pages, Netlify 등 정적 사이트 호스팅이면 어디든 됩니다.
2. 아이폰 **사파리**로 그 주소를 엽니다.
3. 공유 버튼 → **홈 화면에 추가** → 추가.
4. **이후에는 홈 화면 아이콘으로만** 사용하세요. (사파리 탭과 홈 화면 앱은 저장 공간이 따로라서, 사파리에서 입력한 기록은 홈 화면 앱에 보이지 않아요.)

> 앱에는 개인 데이터가 들어 있지 않아요(기록은 폰에만 저장). 그래서 저장소가 공개여도 기록이 노출되지는 않습니다.

## 2. 기록 지키기

- **설정 → 백업 파일 만들기**로 가끔 JSON 파일을 저장해 두세요 (iCloud Drive "파일에 저장" 등).
- 폰을 바꾸면: 새 폰에서 같은 주소를 홈 화면에 추가 → **설정 → 백업 파일 불러오기**.
- 홈 화면에서 앱 아이콘을 삭제하면 기록도 같이 지워집니다. 삭제 전에 꼭 백업하세요.

## 3. 앱을 고쳐서 다시 올릴 때

- 파일을 수정해 다시 올리면서 `sw.js` 맨 위의 `VERSION` 숫자를 올려 주세요. (예: `v1.0.1`)
- 앱을 완전히 닫았다가 두 번 열면 새 버전이 적용됩니다. 기록 데이터는 그대로 유지돼요.

## 4. 파일 구조

```
index.html            진입 페이지
manifest.webmanifest  홈 화면 앱 설정(이름·아이콘)
sw.js                 오프라인 캐시
css/style.css         디자인
icons/                앱 아이콘
js/main.js            시작점·탭·라우터 연결
js/db.js              기기 안 저장(IndexedDB)·백업/복원
js/calc.js            볼륨·1RM·어시스트 계산 (순수 로직)
js/timer.js           휴식 타이머·소리·화면 켜짐 유지
js/session.js         운동 시작/종료, 세트 편집 시트
js/picker.js          운동 검색·선택, 새 운동 만들기
js/views/*.js         홈, 운동 진행, 루틴 편집, 종목, 기록(캘린더), 내 몸, 설정
```

## 5. 알아 둘 점

- **휴식 종료 알림**: 앱이 켜져 있을 때 소리·화면으로 알려요. 화면을 잠그거나 다른 앱으로 가면 아이폰이 웹앱을 멈춰서 알림이 안 올 수 있어요. 그래서 운동 중에는 화면이 꺼지지 않게 유지하는 옵션(기본 켜짐)을 넣었어요. 잠금 상태에서도 확실히 알리려면 서버가 필요한 푸시 알림을 따로 붙여야 합니다.
- 소리는 무음 스위치 상태에 따라 안 들릴 수 있어요.
- 사진은 640px로 줄여서, 움짤(GIF)은 5MB 이하면 원본으로 저장해요.
